# Skills framework: Data Engineer (fictional sample)

This is a fictional skills list written for a course exercise. It imitates the shape of a public occupational skills database but contains no real data.

## Core skills, ranked by importance

1. SQL: joins, window functions, query plans, indexes.
2. Python: scripting, packaging, tests, type hints.
3. ETL and ELT design: batch loads, incremental loads, retries, idempotent jobs.
4. Data modeling: star schemas, slowly changing dimensions, naming conventions.
5. Workflow tools: schedulers, dependency graphs, backfills.
6. Cloud storage and warehouses: object storage, columnar formats, cost control.
7. Data quality: schema checks, null and range checks, alerts when a load looks wrong.

## Supporting skills

Reading other people's code, writing a short design note, explaining a late pipeline to a non-technical manager, and asking what decision a dataset is meant to support.

## Tools learners should recognise

Postgres, a columnar warehouse, a workflow scheduler, a version control system, a container runtime, and a notebook environment for quick checks.

## Signals of entry-level readiness

A learner can load a messy file into a database without losing rows, can explain why a job is safe to run twice, and has one public project that shows a pipeline with tests and a README.
