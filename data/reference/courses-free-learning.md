# Free learning paths for data and AI work (fictional list)

This list is fictional sample data. The course names are made up.

## SQL and databases

- "Query Practice Daily": a 30-day set of small SQL exercises with solutions. About 20 minutes a day.
- "Databases Without the Jargon": a free text course on indexes and query plans.

## Python and pipelines

- "Scripts That Run Twice": a short course on writing idempotent Python jobs and tests.
- "A Month of ETL": a project-based path that builds one pipeline end to end and publishes it.

## Language models and retrieval

- "Embeddings in an Afternoon": explains vectors, cosine similarity and chunking with a small notebook.
- "Retrieval That Cites Its Sources": builds a question-answering tool and a simple evaluation set.

## How to choose

Pick one path and finish it. A finished small project in a public repository is worth more to a hiring manager than three unfinished courses. Match the path to the gap you found in the job description you are aiming at.
