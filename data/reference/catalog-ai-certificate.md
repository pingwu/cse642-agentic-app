# Northgate Institute: Applied AI Certificate (fictional catalog excerpt)

This page is fictional sample data for a course exercise. Northgate Institute does not exist.

## Program overview

The Applied AI Certificate is a part-time program of five courses. Most students finish in two terms. Each course ends with a small project that goes into a public portfolio.

## Courses

| Code | Title | Units | Prerequisite |
|---|---|---|---|
| NI 210 | Python for Data Work | 3 | None |
| NI 220 | SQL and Data Pipelines | 3 | NI 210 |
| NI 310 | Machine Learning Foundations | 3 | NI 210 |
| NI 320 | Working with Language Models | 3 | NI 310 |
| NI 410 | Capstone: Ship an AI Feature | 3 | NI 320 |

## What each course teaches

NI 220 covers extract, transform and load (ETL) work in Python and SQL. Students build a pipeline that reads a messy CSV, cleans it, loads it into Postgres, and schedules it to run every night. The final project is a documented pipeline with tests.

NI 320 covers prompts, structured output, embeddings and retrieval. Students build a question-answering tool over their own documents and measure how often it cites the right source.

## Admission and cost

There is no entrance exam. Applicants need basic Python and a laptop that can run Docker. Tuition is 1,200 dollars per course. Students who finish all five courses receive the certificate and a portfolio review with a career adviser.
