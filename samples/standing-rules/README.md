# Standing rules: example files

Used by the CSE 642 Session 4 Lab manual on standing rules. Copy what you need, then edit it to match how you work.

| File | What it shows |
|---|---|
| `AGENTS.md` | A short instruction file for a MASProjects workspace. About twenty lines, with a reason beside each rule. |
| `CLAUDE.md` | Two lines plus an import of `AGENTS.md`, so Claude Code and other tools read the same rules. |
| `solo-unicorn-rewrite/AGENTS.md` | A short rewrite of the rules in [pingwu/solo-unicorn](https://github.com/pingwu/solo-unicorn). The original constitution is 148 lines. |
| `persona/` | Four small files in the style of OpenClaw and Hermes: `SOUL.md`, `IDENTITY.md`, `USER.md` and `MEMORY.md`. Names and limits vary by tool, so check your tool's docs. |

Keep every file short. Add a rule only after the agent gets something wrong, and delete a rule the agent already follows without it.
